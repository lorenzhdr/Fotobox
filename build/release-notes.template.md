## Fotobox {{VERSION}}

### Welche Datei passt zu meinem PC?

| Datei | Für welchen PC? |
| --- | --- |
| `Fotobox-Setup-{{VERSION}}-x64.exe` | Installer für Windows-PCs mit **Intel- oder AMD-Prozessor** (x64) |
| `Fotobox-Setup-{{VERSION}}-arm64.exe` | Installer für Windows-PCs mit **Snapdragon/ARM-Prozessor** (z. B. Copilot+ PCs) |
| `Fotobox-{{VERSION}}-x64-portable.zip` | Portable Version ohne Installation, Intel/AMD (x64) |
| `Fotobox-{{VERSION}}-arm64-portable.zip` | Portable Version ohne Installation, Snapdragon/ARM |

Unsicher? Unter *Einstellungen → System → Info* steht bei „Systemtyp“, ob es ein x64- oder ein ARM-basierter Prozessor ist.

### Hinweis zu Windows SmartScreen

Die Dateien sind nicht digital signiert. Windows zeigt deshalb beim ersten Start möglicherweise die Meldung „Der Computer wurde durch Windows geschützt“ an.
Klicke dort auf **Weitere Informationen → Trotzdem ausführen**.

### Hinweise

- Die Installation erfolgt standardmäßig nur für den aktuellen Benutzer und benötigt keine Administratorrechte.
- Einstellungen und Protokolle liegen in `%LOCALAPPDATA%\Fotobox`, Fotos standardmäßig unter `Bilder\Fotobox`. Beides bleibt bei einer Deinstallation erhalten.
- Beim ersten Start wird eine Admin-PIN festgelegt. Die Admin-Ansicht öffnest du mit **Strg + Alt + A**.
